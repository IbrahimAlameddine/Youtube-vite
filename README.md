<h1> مسار تطوير واجهة موقع يوتيوبي باستخدام Vite </h1>

<p>
الشيفرة المصدرية الخاصة بمسار تطوير واجهة موقع يوتيوبي (Youtuby) باستخدام
Vite و JavaScript، ضمن <a href="https://academy.hsoub.com/learn/front-end-web-development/">دورة تطوير واجهات المستخدم</a>.
</p>

<h2> تنصيب Node.js و npm </h2>

<p>
لتشغيل هذا المشروع، يجب أن يكون Node.js و npm مثبتين على جهازك.
في حال لم يكونا مثبتين، اتبع الخطوات التالية:
</p>

<p>
 ادخل إلى الموقع الرسمي لـ Node.js:
</p>

<div dir="ltr">
<a href="https://nodejs.org/" target="_blank">https://nodejs.org</a>
</div>

<p>
قم بتحميل النسخة الموصى بها (LTS) ثم تثبيتها على جهازك بالطريقة الاعتيادية.
بعد الانتهاء من التثبيت، افتح الطرفية (Terminal أو Command Prompt) وتأكد من نجاح التثبيت عبر تنفيذ الأوامر التالية:
</p>

<ul dir="ltr">
  <li><code>node --version</code></li>
  <li><code>npm --version</code></li>
</ul>

<p>
في حال ظهرت أرقام الإصدارات، فهذا يعني أن Node.js و npm مثبتان بنجاح.
</p>

<h2> تشغيل المشروع محلياً </h2>

<p>
 ثبت الاعتماديات الخاصة بالمشروع:
</p>

<div dir="ltr"><code><pre>
npm install
</pre></code></div>

<p>
بعد الانتهاء من التثبيت، شغل خادم التطوير:
</p>

<div dir="ltr"><code><pre>
npm run dev
</pre></code></div>

<p>
سيقوم Vite بتشغيل المشروع، وسيظهر في الطرفية رابط المعاينة، وغالباً يكون على العنوان:
</p>

<div dir="ltr"><code><pre>
http://localhost:5173
</pre></code></div>

<p>
افتح الرابط في المتصفح لمشاهدة المشروع.
</p>

</div>
